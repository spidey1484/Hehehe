# Love Letter Website

A romantic surprise page: rose-fall intro → "From me to you" → poem → heart lock → passkey → photo polaroids → typed letter → closing line.

## Customise (all in `script.js`, top of the file)
- `passkey` – the 4-digit code (default `1234`)
- `photos` – list of your photos (put them in the `images/` folder: `1.jpg`, `2.jpg`, …)
- `letter` – your personal note

Other text (title, poem, "From, your forever") is in `index.html`. Replace `assets/couple.svg` with your own illustration if you like.

## Upload to GitHub Pages
1. Create a new repository on GitHub and upload all files of this folder.
2. Go to **Settings → Pages**.
3. Under *Build and deployment* choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://<username>.github.io/<repo-name>/`.
