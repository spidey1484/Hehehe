LOVE FLOWER STYLE RECREATION
==============================

This package recreates the visual flow shown in your screen recording from scratch.

Included:
- Gift landing screen
- Dark brown/pink theme
- Story section
- Decorative flowers/hearts
- Passkey screen with 4-digit dots
- Number keypad + Clear button
- Unlocked transition
- Flower loading screen
- Polaroid-style memory wall
- Long memory note section
- Final message section
- Floating heart particles
- Optional background music
- Responsive mobile layout

PERSONAL EDITING
----------------
Open config.js and change:
- passkey
- senderName / receiverName
- all headings/messages
- memory photo file paths
- music file path

ASSET FOLDERS
-------------
Put your six supplied original assets here:
assets/giftbox.png
assets/photos/locked.png
assets/photos/rose.png
assets/photos/centre.png
assets/flowers/flower-1.png
assets/flowers/flower-2.png

For your own memory photos:
assets/memories/photo1.jpg ... photo7.jpg

For music:
assets/music.mp3

The design is recreated from the visible recording, not copied from the site's private/source code.
